# 字幕时间轴修整器

本地运行的字幕时间轴修整 Web 应用：Node.js + Express 后端，原生 HTML/CSS/JS 前端（无任何前端框架与构建步骤）。

## 功能

- **导入 SRT**：点击「导入 SRT」选择文件，或直接把 `.srt` 文件拖入页面；导入时自动规整（排序、负起点归零、补足最短时长、后移重叠块），保证初始状态合法
- **可缩放时间轴**：缩放滑杆 / ＋− 按钮 / `Ctrl+滚轮`（以光标为锚点）/「适应宽度」
- **拖动修整**：拖动任意字幕块的左/右边界调整起止时间，实时保证：
  - 每块时长 **≥ 500ms**
  - 相邻块间隔 **≥ 100ms**
  - 起点 **≥ 0**
- **整块平移**：按住字幕块主体横向拖动，时长保持不变：
  - 向左在 **0** 与**前驱 100ms 安全线**处夹取
  - 向右越过后继安全线时**递归推移**所有受影响的后继块（保持各自时长）
  - 同一次手势内先右推再左回拖，已被推开的后继**不自动回拉**；松手仅生成**一条**撤销记录
- **递归推移**：右边界越过后继安全线时，超出量递归推移所有受影响的后继块，且保持各块时长不变；向回拖动只释放空隙，不自动拉回后继
- **同步显示**：拖动过程中时间轴块、下方列表与状态栏实时同步显示文本与时间码
- **撤销**：「撤销拖动」按钮或 `Ctrl+Z`，可撤销最近一次（及更早的）拖动
- **导出 SRT**：导出前再次校验约束，生成序号重排、格式合法的 `.srt` 文件下载

## 一键启动（Docker）

```bash
docker compose up --build
```

然后访问 **http://localhost:3000**（端口 3000）。

依赖安装与初始化已纳入镜像构建与启动流程，无需任何额外命令。

## 本地启动（无 Docker）

```bash
./start.sh          # 自动安装依赖并启动；等价于 npm install && npm start
```

同样访问 http://localhost:3000 。可用 `PORT` 环境变量改端口：`PORT=8080 npm start`。

## 测试

```bash
npm test            # node --test，覆盖时间码解析、SRT 读写、约束引擎、整块平移与推移规则
```

## 项目结构

```
├── server.js            # Express：托管静态页面 + /api/health
├── public/
│   ├── index.html       # 页面结构
│   ├── styles.css       # 样式
│   ├── engine.js        # 约束引擎（浏览器/Node 共用）：解析、导出、拖动约束、整块平移、递归推移
│   └── app.js           # 前端交互：时间轴渲染、拖动、缩放、撤销、导入导出
├── test/engine.test.js  # 引擎单元测试
├── Dockerfile           # 依赖安装纳入构建，CMD 直接启动
├── docker-compose.yml   # 一键启动
└── start.sh             # 本地一键启动（自动装依赖）
```
